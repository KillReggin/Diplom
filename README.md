# 🍇 Прогнозирование объема урожайности 

## 📌 Описание проекта

Проект предназначен для оценки массы виноградных гроздей по изображению.

Алгоритм:
1. Детекция гроздей (YOLO)
2. Аппроксимация формы (усечённый конус)
3. Расчёт объёма
4. Оценка веса через нормализацию
5. Генерация PDF-отчёта с 3D визуализацией

⚠️ В рамках baseline используется предобученная модель, не обученная на production-данных.

---

## 🚀 Как запустить

- pip install -r requirements.txt
- python -m app.interface_adapters.cli
